# Competencia

El mercado está **fragmentado**: cada uno hace una pieza, nadie lo une todo. Ese es
el hueco de [[Producto|Noesis]].

## Directos / referentes
- **Forjia** (getforjia.com) — el más parecido. Factura/gastos por WhatsApp con voz,
  Verifactu + TicketBAI y funciones operativas que ya incluyen agenda y seguimiento.
  Es el competidor a vigilar; sus capacidades y precios deben verificarse
  periódicamente porque el producto evoluciona.
- **Experi** (Mallorca) — agenda citas por WhatsApp 24/7. Sin facturación.
- **Javadex / OptimusCall / AI Hispania** — agentes de voz que contestan el teléfono
  para gremios. Sin la parte administrativa.
- **Holded / Quipu / Billin** — ERP/contabilidad completos, ya homologados Verifactu.
  Nadie los abre desde el móvil; los usamos vía API (ver [[Arquitectura]] y [[Fiscalidad]]).

## Lección estratégica
Ver [[Decisiones]]: no copiar código (es propietario), estudiar **ideas/UX** y construir
con open-source. Diferenciarse en el ciclo completo trabajo → factura → cobro,
proactividad y control web, no en una sola función que otro competidor pueda añadir.
