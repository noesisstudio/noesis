# Textos legales de Veri*Factu archivados

Retirados de la web el 2026-09-14 por decisión del founder: Veri*Factu aún no está
disponible y la web no debe nombrarlo. Se conservan aquí, tal como estaban, para
volver a publicarlos cuando la implementación esté validada con la AEAT.

## `cumplimiento.html` · antigua sección 2

Ubicación original: entre «1. Estar dado de alta para facturar» y «Protección de
datos de tus clientes (RGPD)». Al quitarla, las secciones siguientes se
renumeraron (3→2, 4→3, 5→4, 6→5).

```html
<h2>2. Facturación electrónica y Verifactu</h2>
<p>La normativa antifraude (Verifactu / sistemas de facturación verificables) exige que
  el software de facturación cumpla requisitos técnicos, de integridad y conservación.
  Bynoesis está preparando una <b>implementación propia</b>; no depende de un supuesto
  sello u homologación de un tercero. No presentamos esa implementación como
  definitivamente conforme hasta completar sus pruebas con la AEAT, la documentación
  técnica y la declaración responsable exigible. La transmisión se mantiene desactivada
  mientras no esté configurada y validada. Consulta con tu asesor el calendario que te
  aplica.</p>
```
